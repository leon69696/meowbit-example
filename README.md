# Meowbit Example

A minimal example repository for working with Meowbit (Microsoft MakeCode Arcade).

## Overview
This project contains examples and resources to build and flash games to a Meowbit device using MakeCode Arcade or MicroPython.

## Prerequisites
- Meowbit device and USB cable
- Browser with access to MakeCode Arcade
- Host machine (dev container runs on Ubuntu 24.04.2 LTS)

## Notes
- Use the MakeCode editor for block/JavaScript/TypeScript development.
- For MicroPython support, follow the Meowbit MicroPython docs on the hardware page.
